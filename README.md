## 📋 Enfoque de Producto & Gestión (Functional Analysis & PM)

Este proyecto no es solo una página web estática; está conceptualizado, documentado y estructurado bajo los estándares de la gestión de proyectos ágiles:
* **Trazabilidad de Requerimientos:** Cada ticket en el tablero representa un entregable real, desglosado en historias de usuario, criterios de aceptación bajo metodología BDD y estimaciones de esfuerzo.
* **Visión Integral:** Conecta el desarrollo de software con las necesidades del negocio, priorizando la claridad en los flujos, especificaciones funcionales y validaciones de calidad.

---

## 🛠️ Stack Tecnológico & Core Skills

* **Frontend:** Astro, Tailwind CSS, TypeScript.
* **Gestión & Diseño:** Jira / Confluence (Simulación de flujos), Figma (UX/UI Wireframing).
* **Calidad & Testing:** ISTQB, Postman (API Testing), Pruebas de integración y automatización de endpoints.
* **Metodologías:** Scrum, Kanban, Ciclo de Vida del Software (SDLC).
